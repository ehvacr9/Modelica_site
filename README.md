# Modelica Studio 網頁

以 OpenModelica 建立電路模型的靜態網站，適合部署到 GitHub Pages。元件庫包含直流電壓源、電阻、電容及接地；可連線、設定參數、匯入／匯出 JSON，並顯示 Modelica 程式碼和電容電壓曲線。

## 模擬方式

使用 OpenModelica 官方 Playground 的瀏覽器版 WebAssembly 編譯器，在瀏覽器本機執行模型，而非呼叫 OMWebBook 的遠端模擬 API。模型及其模擬結果不會由本網站上傳到伺服器。首次執行須下載約 75 MB 編譯器與 Modelica Standard Library；函式庫由 OpenModelica 指定的來源下載，因此需要網路。載入和模擬速度取決於網路、瀏覽器及電腦效能。

此版本的 OpenModelica 是開發版，瀏覽器的支援能力與官方資源可用性可能改變；若資源下載或模擬失敗，介面會顯示錯誤。需使用支援 WebAssembly 與 module worker 的現代瀏覽器。複雜電路、多物理領域與完整 Modelica 編輯尚不支援。

## 工作區

- **建模 → 模型視圖**：編輯電路與參數；使用畫布下方的**程式碼視圖**查看、複製產生的唯讀 Modelica 程式碼。
- 電氣元件使用 IEEE 315 風格的基本電路符號，預設直立，直流電壓源為上正下負，接地端點在上方。選取元件後，可按「向左 90°」或「向右 90°」旋轉；名稱及數值保持水平，端點與連線同步更新。方向儲存在匯出的 JSON 中；匯入舊版模型時保留原本的方向。旋轉不會改變電氣模型或清除模擬結果。
- 在畫布空白處拖曳可平移，滾輪或「＋／−」按鈕可縮放；按「填滿視窗」可將全部元件置於畫布可見範圍。元件位置可延伸至畫布可視區域以外，並隨模型匯出；空白模型的「填滿視窗」會還原初始視角。
- 在桌面版面中，畫布會隨瀏覽器高度伸縮，模型視圖與程式碼視圖分頁位於建模工作區底部；畫面高度不足時可捲動頁面。
- 滑鼠停在線段上時，僅突出顯示目前的線段至下一個轉折或接點；拖曳仍會移動該直線段，點擊則會確認刪除整條連線及其分支。元件靠近時會縮小繞線間距；若端點被其他元件遮住而無法繞出，仍需移開重疊元件。
- 拖曳元件時，優先調整該元件端點附近的線段，保留其餘路徑及分支接點位置；拖曳接地分支時，接點會移至主線上靠近接地端點的位置並重新繞線。若移動後線路受阻或無法維持端點方向，受影響的線路會重新繞線。調整後的路徑會隨模型儲存。
- 拖曳連接接點的分支末段時，接點會沿相交的主線滑動並吸附格點；無法維持連接或避開元件的位置不會套用。
- 元件、端點、線段與分支接點會吸附至 12 單位格點；格點會隨畫布平移及縮放。匯入舊模型時會自動對齊，若無法保留手動路徑則重新繞線並提示；電氣連接不變。
- 按「優化布局」會依連接分組，對多組元件排列和間距進行整體繞線評分，偏好較少交叉、轉折及較短的線路；電壓源與電容直立、電阻水平、接地置於下方。搜尋為有限候選的啟發式方法，不能保證任意電路的數學全局最佳解；大型電路會減少候選數。既有手動線路會在確認後由新布局取代；若無法完成繞線，原布局不會變更。不同網路的重疊或過近交叉仍可能需要手動調整，畫面會顯示警告。此功能不改變電氣連接或清除模擬結果。
- 載入範例時會套用相同的優化布局；對未修改的範例再次優化，不會改變電路圖。
- 點擊元件端點後，可點擊既有線段以建立電氣分支及接點；已連接到該電氣網路的端點不會重複連接。接點隨主線重新繞線或拖曳移動，分支會重新繞線。刪除主線時會列出並確認一併刪除的所有分支；刪除主線端點所屬元件也會一併移除相關分支。分支資訊會保存在匯出的 JSON 中。
- 連線會隨元件位置自動繞開元件。用滑鼠左鍵拖曳線段可調整位置；調整只影響圖形，不改變電氣模型或清除模擬結果，並會存入 JSON。若手動路徑因元件移動、旋轉或遮擋而失效，畫面暫時改用自動繞線並顯示提示；原手動路徑仍會保留，直到重新拖曳或恢復可用。無法繞線時會顯示紅色虛線及警告。點擊連線後須確認才會刪除。
- 已電氣連接的線路分支在三條以上線段交會處顯示接點；兩條穿過彼此的線段則以跨線拱形表示，即使它們在別處連接亦然。跨線不會建立新的電氣連接。不同網路的線段重疊或跨線太靠近線段端點時會顯示警告，請手動分開線段。
- 模擬完成後，切換至**結果**頁，右側的**變數工作區**顯示每個變數的名稱與最後一筆數值。若修改模型或模擬設定，舊結果會清除，需重新模擬。
- 選取變數工作區中的變數可顯示該變數隨時間的曲線。預設圖表為第一個電容的電壓，若沒有電容則為第一個非時間變數。
- 結果頁右側變數工作區上方提供播放、暫停、速度與進度控制，重播**已完成**的暫態結果，並非控制正在執行的 OpenModelica。切換變數會保留重播時間；變數工作區的數值仍為模擬結束時的值。
- 播放速度初始為 1 倍，可自行調整。繪圖縱軸顯示刻度及目前支援的電壓、電流、電阻、損耗功率、時間及其變化率的物理量與單位；CSV 未提供單位資訊，無法辨識的變數會標示「物理量與單位未知」。

## 本機預覽

在此資料夾執行（Python 僅供本機預覽，GitHub Pages 不需要 Python）：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

使用瀏覽器開啟 <http://127.0.0.1:8000/>。不要直接以 `file://` 開啟，因為瀏覽器會限制 worker 與資源載入。按 `Ctrl+C` 停止。

開啟 <http://127.0.0.1:8000/tests/engine.html> 可執行結果解析與模型驗證測試，<http://127.0.0.1:8000/tests/replay.html> 可測試介面和結果重播，<http://127.0.0.1:8000/tests/canvas.html> 可測試畫布視角；實際模擬仍需網路下載 Modelica 函式庫。

## GitHub Pages

將本資料夾推送至 GitHub 儲存庫的 `main` 分支，在儲存庫 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。推送後執行 `.github/workflows/pages.yml`，並從 Actions 或 Pages 設定查看發布狀態及網址。
